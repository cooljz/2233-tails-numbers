# 2233 尾号工具

中国银行 2233 万事达借记卡自选尾号的校验与枚举工具。单个 `index.html`，在浏览器里运行，不需要安装，也不会上传你输入的任何内容。

在线使用：https://cooljz.github.io/2233-tails-numbers/

## 功能

- **按尾号查询**：选好地区位，输入 5 位或 6 位自选尾号，列出所有可能的完整卡号，可以复制单个或全部可用号码。
- **校验完整卡号**：输入 16 位卡号，检查前缀、校验位和已开启的选号规则，并拆解出地区位、系统位、自选位。
- **规则开关**：较确定的规则默认开启，没有依据的默认关闭，每一条都可以自己切换，设置保存在浏览器里。

## 卡号结构

16 位卡号分成五段：

| 位置 | 含义 | 说明 |
|---|---|---|
| 第 1–6 位 | 固定前缀 | `223300` |
| 第 7–8 位 | 地区位 | 开卡分行 |
| 第 9–10 位 | 系统位 | 系统派发，不能选 |
| 第 11–15 位 | 自选位 | 你选的数字 |
| 第 16 位 | 校验位 | Luhn 算法；选 6 位时这一位也由你选，必须满足校验 |

选 5 位时，第 16 位由系统按校验规则生成，所以每个系统位组合（00–99）都有对应的卡号。选 6 位时，只有满足校验的系统位组合才存在，大约十分之一的组合能通过，也可能一个都没有。

## 选号规则

| 规则 | 默认 | 说明 |
|---|---|---|
| 连续 3 个及以上相同数字不可选 | 开 | 论坛帖称不能出现 3 个及以上相同数字（如 888），只检查自选数字 |
| 连号检查扩大到第 9–16 位 | 关 | 把系统位和末位校验位也算进连号检查，没有来源 |
| 地区位必须在已知分行表内 | 关 | 分行表来自论坛，未核实 |

校验位（Luhn）始终检查，不能关闭。另外可以调整系统位（第 9–10 位）的范围，默认 00–99。
